# PlanetB 3D - Interactive Solar System Explorer
## Description

PlanetB is an interactive web application that allows users to explore Earth, explore the Solar System, and visualize planets from video games, including Outer Wilds and Halo. The application combines Cesium.js for Earth mapping and Three.js for 3D planetary visualization.

## Features | Earth Exploration

- 3D globe with satellite imagery, terrain maps, and various map layers

- Search for any location in the world using OpenStreetMap

- Markers for famous landmarks and the 7 Wonders of the Modern World

- Partial Street View integration with Google Maps

- Real-time weather data for any city (requires an OpenWeatherMap API key)

- Visualization of the Northern Lights in the polar regions

- Dynamic cloud layer with rotation

- Distance measurement tool between two points on the globe

- Automatic camera rotation mode

## Solar System

- All 8 planets plus Pluto with realistic textures

- Saturn and Uranus ring systems

- Orbital paths with adjustable speed (0.1x to 10x)

- Planet labels and orbit toggles

- Pause/play orbital movement

- Detailed information panel for each planet with scientific data

# Technologies Used
- `Cesium.js 1.113` - 3D globe rendering

- `Three.js r128` - 3D scene rendering for planets and ISS

- `OpenStreetMap API` - Location search

- `WhereTheISS API` - Real-time ISS position tracking

- `OpenWeatherMap API` - Weather data

- `Google Maps Street View` - Panoramic views

# Keyboard Shortcuts

- `R` - Toggle auto-rotation

- `H` - Reset camera view

- `F` - Toggle fullscreen mode

- `G` - Toggle grid overlay

- `ESC` - Stop auto-rotation
